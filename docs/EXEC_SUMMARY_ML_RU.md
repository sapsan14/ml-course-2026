# Исполнительное резюме (ML Course 2026)

Этот репозиторий приведен к lean-формату для учебы:

- Вся практика собрана в `exercises/`.
- Методические материалы собраны в `docs/`.
- Удалены служебные и инфраструктурные файлы, не относящиеся к учебному процессу.

## Что важно

- Для заданий, где доступны обе версии, сохранены оба ноутбука:
  - русская версия: `*_ru.ipynb`
  - эстонская версия: `*_et.ipynb`
- Датасеты оставлены только необходимые для запуска упражнений.
- Корневой `README.md` отражает новую минимальную структуру.

## Рекомендация по работе

1. Запускайте ноутбуки из `exercises/`.
2. Выбирайте языковую версию задания по суффиксу файла (`_ru` или `_et`).
3. Пользуйтесь [study_guide_ru.md](study_guide_ru.md) как основным учебным гидом.
4. Для недели 7 ориентируйтесь на [week7_submission_pack.md](week7_submission_pack.md) и ноутбуки в `../exercises/week07_ann/` и `../exercises/week07_cnn/`.
